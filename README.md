# Deep Learning for Time Series Forecasting

Group members: Cheng Yexuan, Jiao Zijun, Rong Rong, Xue Yuting, Zhou Jiayu

## Project Overview

This project collects multiple classical and deep learning approaches for time series prediction, including but not limited to:
- Light Gradient Boosting Machine (LGBM)
- Prophet
- DLinear
- Long Short-Term Memory(LSTM)
- DARNN
- Transformer


## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/jiaozijun666/DL-for-time-series-forecasting.git
   cd DL-for-time-series-forecasting
   ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run examples:
   ```bash
   python experiments/lgbm_all.py
   ```
